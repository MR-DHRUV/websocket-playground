# WebSocket Playground

A high-performance, universal WebSocket testing suite and interactive JSON debugger built with **React 19**, **Vite**, **Tailwind CSS**, and **Shadcn UI** components. Designed as a standalone, developer-centric tool for testing any real-time WebSocket backend, API gateway, pub/sub stream, or microservice.

---

## 🚀 Quick Start

### Installation & Run:
```bash
# Clone or navigate to the directory:
cd websocket-playground

# Install dependencies:
npm install

# Start the dev server:
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
